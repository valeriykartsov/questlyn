# Questlyn — Design Brief

## Brand Identity

### Product Name

Questlyn

### Brand Direction

The visual identity should communicate a combination of:

- Adventure and exploration
- Personal growth and progression
- Purposeful action
- A sense of discovery
- Modern digital product quality

Questlyn should feel like a polished contemporary application,
not a generic fantasy game interface.

### Design Requirements

The brand identity stage must include:

1. Logo concepts
2. App icon concepts
3. Color palette
4. Typography
5. Iconography and visual language
6. Character visual direction
7. UI component direction
8. Key screen mockups
9. Interactive prototype

The design must be reviewed and approved before substantial
production implementation begins.

### Naming Consideration

The name Questlyn is approved as the product name.
Do not generate alternative product names unless explicitly requested.

Trademark and domain verification remain a pre-release task.

## Решения по визуалу (10.11.2026)

- Персонаж — иллюстрированный, минималистичный, в pixel art (_подтверждено 10.11.2026_).
- Игровой мир — окружение: персонаж движется по карте, события календаря формируют ландшафт, Wellbeing задаёт погоду.
- Журнал квестов — метафора «журнала квестов» из RPG (референс по ощущению — Genshin Impact). Дизайн оригинальный: метафору берём, чужой UI и стиль не копируем.
