# Questlyn — MVP и план поставки

Статус состава MVP: **Рабочая гипотеза** (из Concept Audit v0, 10.11.2026). Окончательное решение — после прототипа.

## Состав MVP

- **Входит:** стартовый онбординг (формирует первую БД); персонаж; 1–3 профессии с атрибутами; Class; навыки; Quest (без даты / дата / дата и время, опциональный Epic); Epic Quest; Daily и Weekly Quest; Activity; выполнение → начисление → экран «что изменилось»; атрибуты, FOC/DIS, Adventurer Rank; журнал квестов; экран «Сегодня»; повестка по датам; локальная БД; автоматический бэкап; экспорт; HP и MP; сон (HealthKit + ручной ввод); вредные привычки; Летопись героя (добавлено 10.11.2026).
- **Также входит:** каталог профессий + ручное пополнение; Mastery и Condition навыка; изометрическая карта дня с погодой (см. ниже); ручной mood check-in + HealthKit State of Mind; бэкап в iCloud Drive.
- **Карта дня (изометрическая):** входит в MVP — миниатюра на «Сегодня» и обзор по дням; события из Apple Calendar (EventKit, только чтение), маркеры квестов, метки настроения, погода.
- **Отложено:** Confidence навыка, запись в Apple Calendar, TimeBlocks, World Events, виджеты, watchOS, синхронизация.
- **Исключено:** Equipment.

## Этапы

1. ✅ Concept Audit v0.
2. Закрытие открытых вопросов (06), документ формул.
3. Дизайн: направления → логотип и иконка → палитра, типографика, иконки → персонаж (pixel art) → сценарии → wireframes → макеты → review → кликабельный прототип.
4. Вертикальный срез: онбординг → персонаж → профессия → класс → атрибуты → навык → квест → выполнение → прогресс → перезапуск с сохранённым состоянием.
5. Реальное использование, итерации.

- 10.11.2026 добавлены экраны: онбординг (герой, атрибуты профессий, название класса), новый навык, карточка квеста, Epic Quest, отметка настроения, календарь, настройки. Экраны связаны ссылками.
- Подтверждено 10.11.2026: внешность героя — волосы и кожа на выбор; шкала настроения из трёх значений; выбор темы (системная / светлая / тёмная).
- 10.11.2026 собран интерактивный прототип (артборд «Интерактивный прототип» на холсте): онбординг из 4 шагов → «Сегодня» → привычки и квесты → «Квест выполнен» с начислениями по Rule Set v1 и отменой → журнал → герой с рангом → карта дня → отметка настроения → создание квеста с размером S/M/L. DEX убран со всех экранов и из прототипа (кроме исторических досок направлений A/B/C); прототип пересчитан на приоритет ×0,5/×1/×1,5.
