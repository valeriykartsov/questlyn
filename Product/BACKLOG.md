# Questlyn — План реализации и бэклог

Статус плана: **Рабочая гипотеза** (составлен 10.11.2026). Порядок этапов и состав можно менять — изменения фиксируются в журнале внизу.

**Главный принцип плана — Working Product First.** Версия, которую можно поставить на свой iPhone и пользоваться ей, появляется в конце этапа 1. Каждый следующий этап тоже заканчивается рабочей сборкой на телефоне.

## Как отмечать прогресс

- `[ ]` — не начато, `[~]` — в работе, `[x]` — готово. У готовой задачи — дата: `[x] 1.3 … — 12.11.2026`. Хеш коммита можно дописать следующим коммитом.
- Отметку ставит тот, кто сделал задачу, в том же коммите, что и саму работу.
- Задачу, которая оказалась ненужной, не удаляют, а зачёркивают с причиной.
- Новая работа «на потом» добавляется в самый низ, в раздел «На потом».
- Правила продукта — в 02, 07, 08. Если задача расходится с ними — остановиться и вынести вопрос пользователю.

## Этап 1. Первый цикл квеста — первая версия «в руки»

Цель — самый короткий путь к приложению, которым уже можно пользоваться каждый день как таск-трекером с ростом героя.

- [ ] 1.1 Каталог профессий в бандле (с версией): «Инженер-программист», «Атлет-любитель», «Менеджер проектов», «Баскетболист», «Промпт-инженер» и другие — без DEX.
- [ ] 1.2 Короткий онбординг: имя героя → 1–3 профессии → название класса. Создаёт первую БД.
- [ ] 1.3 Навык: создание навыка в профессии (название). Mastery и Condition — позже.
- [ ] 1.4 Квест: название, описание (необязательно), приоритет (по умолчанию «Средний»), навык (необязательно), дата и время (необязательно).
- [ ] 1.5 Экран «Сегодня» (без карты и HP/MP): квесты на сегодня, атрибуты, кнопка «+».
- [ ] 1.6 Выполнение квеста → `ProgressGrant` по Rule Set v1.1: FOC, навык, атрибуты по приоритетам профессии, Class Multiplier, centiXP, идемпотентность по `sourceId`.
- [ ] 1.7 Экран «Квест выполнен»: что изменилось и почему; отмена выполнения удаляет начисления.
- [ ] 1.8 Экран «Герой»: атрибуты и уровни (стоимость 20 + 5L), ранг по очкам и порогам T(r), названия рангов.
- [ ] 1.9 Тесты правил: перенести `Design/tools/rules_sim.py` в тесты Domain — те же сценарии дают те же уровни и ранг.
- [ ] 1.10 Сборка на iPhone. Готово, когда: создаю квест, выполняю, вижу начисления и рост, отменяю, перезапускаю — данные на месте.

- [ ] 2.1 Журнал квестов: фильтры (Все, Квесты, Ежедневные, Недельные, Epic), секции, поиск.

- [ ] 2.7 Карточка квеста: изменить, перенести.
- [ ] 2.8 Сборка на iPhone.

## Этап 3. Честный прогресс

- [ ] 3.1 Спад атрибутов (D-01): 7 дней льготы, −2% в день, граница 70% пика, пик хранится; FOC спадает, DIS — по своему правилу.
- [ ] 3.2 Навыки: Condition (+20 за практику, спад −3 в день, граница 40), Mastery (ручная оценка), неактивные навыки при смене профессии.
- [ ] 3.3 Activity: шаблоны типов, 10 XP в час, предел 3 часа одного типа в день, без двойного начисления с квестом.
- [ ] 3.4 Объяснимость: причины каждого начисления и спада («Подробнее»).
- [ ] 3.5 Полный онбординг: внешность (волосы, кожа), экран атрибутов профессий, класс; ручное добавление профессии; каталог до 20–30 профессий.
- [ ] 3.6 Пиксельный персонаж v1 (плащ по основной профессии). Перед этим — финальный персонаж в дизайне (D-3).
- [ ] 3.7 Сборка на iPhone.

## Этап 4. Состояние героя: HP, MP, сон, вредные привычки

Правила — 08.

- [ ] 4.1 HP и MP: максимумы от уровней, расход MP за квест, проекция из фактов, возврат при отмене. Полосы на «Сегодня» и «Герое».
- [ ] 4.2 Сон: `SleepSession`, ручной ввод утром («Как спали?»), качество Q = D × R, нет данных → 0,5.
- [ ] 4.3 Экран «Утро: итог сна».
- [ ] 4.4 Вредные привычки в листе отметки (блок «Здоровье»): курение −3% за отметку, фастфуд и кофеин после 16:00 −5%, своя привычка.
- [ ] 4.5 Алкоголь — дебаф INT (вариант А): −10% / −25% уровня на 24 часа, действующий INT и MaxMP.
- [ ] 4.6 Настройки «Здоровье героя»: окно сна (23:00–07:00), норма шагов (6000, шаг 500), список привычек.
- [ ] 4.7 HealthKit (только чтение): Sleep Analysis и шаги; сидячий день −5% HP в 23:59, если шагов меньше нормы; нет данных — нет урона.
- [ ] 4.8 Статусы героя: «Истощён» (MP 0), «Ранен» — только вид и подсказки, без влияния на XP.
- [ ] 4.9 Сборка на iPhone.
